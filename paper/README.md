# SeqSubmit BioHackrXiv paper

Source for the BioHackrXiv preprint documenting `nf-core/seqsubmit` v1.

## Layout

- `paper.md` — manuscript (Markdown + YAML metadata header)
- `paper.bib` — bibliography, cited in `paper.md` with `[@key]`

## Previewing as PDF

Push this repo to GitHub, then paste its URL into the [BioHackrXiv Preview Server](http://preview.biohackrxiv.org/) to generate a PDF. Alternatively, run the [bhxiv-gen-pdf](https://github.com/biohackrxiv/bhxiv-gen-pdf) tool locally.
